Bloc 2 - Exemples CSS: espai i caixa

Box Model

Resultat visible

content-box: width + padding + border
border-box: width total fixa

Observa la diferència d'amplada final entre les dues caixes.

Codi HTML

<div class="card-content-box">content-box: width + padding + border</div>
<div class="card-border-box">border-box: width total fixa</div>

Codi CSS

.card-content-box {
  box-sizing: content-box;
  width: 320px;
  padding: 16px;
  border: 2px solid #334155;
  margin: 12px 0;
  background: #e2e8f0;
}
.card-border-box {
  box-sizing: border-box;
  width: 320px;
  padding: 16px;
  border: 2px solid #334155;
  margin: 12px 0;
  background: #bae6fd;
}

Resultat: La primera caixa fa 356px d'amplada visible (320 + 32 de padding + 4 de vora); la segona fa 320px.

Per què passa? content-box aplica width només al contingut. border-box inclou padding i vora dins de width i deixa 284px per al contingut. Els marges queden fora de totes dues caixes.

Cascada

Resultat visible

Aquest text queda en #0f172a per ordre d'aparició de regles.

Codi HTML

<div class="cascade">
  <p>Aquest text queda en #0f172a.</p>
</div>

Codi CSS

.cascade p { color: #475569; }
.cascade p { color: #0f172a; }

Resultat: El text és gairebé negre: #0f172a.

Per què passa? Les dues regles tenen la mateixa importància i especificitat: guanya la darrera. Si afegeixes !important a la primera declaració, guanyarà el gris #475569.

Especificitat

Resultat visible

Guanya el selector per ID en aquest exemple.

Codi HTML

<p id="intro" class="text-destacat">Guanya el selector per ID en aquest exemple.</p>

Codi CSS

p { color: #334155; }
.text-destacat { color: #1d4ed8; }
#intro { color: #b91c1c; }

Resultat: El text és vermell (#b91c1c).

Per què passa? Amb la mateixa importància, l'ID té més especificitat que la classe i l'etiqueta. Si lleves l'ID, guanya la classe (blau); si lleves també la classe, guanya l'etiqueta (gris).

Títol amb rem

Contenidor fluid amb % i límit en rem.

Codi HTML

<div class="contenidor">
  <h3>Títol amb rem</h3>
  <p class="seccio">Contenidor fluid amb % i límit en rem.</p>
</div>

Codi CSS

html { font-size: 16px; }
* { box-sizing: border-box; }
.contenidor {
  width: min(92%, 70rem);
  margin-inline: auto;
  padding: 1rem;
  border: 1px dashed #94a3b8;
}
h3 { font-size: 2rem; margin: 0 0 0.5rem 0; }
.seccio { margin-block: 2rem; }

Resultat: El títol té una mida de lletra de 32px i el contenidor té 16px de padding. Si el pare ofereix 1000px, el contenidor fa 920px; si ofereix 1400px, fa 1120px.

Per què passa? rem depèn dels 16px de l'arrel. El percentatge depèn de l'amplada disponible del pare i min() tria el menor valor entre 92% i 1120px. Els marges automàtics centren la caixa. Els marges verticals del títol (8px) i el paràgraf (32px) col·lapsen: la separació és de 32px, no de 40px.
