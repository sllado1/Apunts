## Organització del cicle

La millor manera d'organitzar el contingut és mantenir una jerarquia clara:

1. `index.md` principal del lloc
2. `DAW/index.md` com a portada del cicle
3. una carpeta per a cada mòdul
4. una portada `index.md` dins de cada mòdul
5. un fitxer per a cada bloc, unitat o tema
