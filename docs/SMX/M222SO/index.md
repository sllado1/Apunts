# M222 — Sistemes operatius monolloc

En aquest mòdul de **1r de SMX** aprendrem com un sistema operatiu permet utilitzar un ordinador i com gestiona els programes, la memòria, els fitxers i els dispositius.

Començarem amb una pregunta bàsica: **què són les dades amb què treballa un ordinador i com les representa?** Aquesta base ens ajudarà a entendre després el funcionament del sistema operatiu.
